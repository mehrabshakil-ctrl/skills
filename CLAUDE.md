# Operating model

All work routes through `chief-of-staff` (see `docs/ORGANOGRAM.md`). Agents live in `.claude/agents/`, skills in `.claude/skills/`.

- Reply to the owner in concise English; tables for structured data; lead with the outcome.
- Owner-only decisions (money, legal, public publishing, credentials) are always escalated, never assumed.
- Never commit secrets. Verify before claiming done; state what was not verified.
